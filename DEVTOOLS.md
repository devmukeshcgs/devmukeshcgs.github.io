# React DevTools

This project includes the standalone React DevTools as a dev dependency and an npm script to launch it.

Install dependencies (if not already installed):

```bash
npm install
```

Run your app and the DevTools in separate terminals:

```bash
npm start
npm run devtools
```

The DevTools window will open and should detect your running React app. You can also install the React DevTools browser extension for Chrome/Firefox for in-browser inspection.
